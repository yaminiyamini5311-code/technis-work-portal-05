PROBLEM SUMMARY
================================================================================

The CEO login worked, but the CEO Portal got 403 errors on these routes:
- GET /api/admin/stats
- GET /api/admin/progress?period=week
- GET /api/tasks/submissions
- GET /api/notifications

Logs showed:
"[SECURITY] CEO token rejected on student/user route: /submissions"
"[SECURITY] CEO token rejected on student/user route: /"

================================================================================
ROOT CAUSES IDENTIFIED
================================================================================

1. Admin routes used authorizeRoles("admin", "manager") but didn't include "ceo"
2. checkStudentRegistrationStatus middleware rejected ALL CEO tokens
3. Notifications route had checkStudentRegistrationStatus applied globally
4. Task routes had checkStudentRegistrationStatus applied globally
5. No special handling for CEO in notification queries (CEO has no user_id)
